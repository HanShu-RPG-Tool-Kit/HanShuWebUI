# 汉书 .hs 语法说明（给作者 & Agent）

本文约定剧本文件（`.hs`）的正式语法。**写出的内容必须能通过这些规则**；不确定时宁可少写，不要发明语法。

---

## 1. 角色对白块

### 规则
- 角色名：仅 `[A-Za-z_][A-Za-z0-9_]*`（字母/数字/下划线，不能以数字开头）
- 多行：`name:` 独占开头，正文若干行，**单独一行** `//` 结束
- 单行：`name:正文//`
- 选项行**不能**出现在对白块内部

### 正例
```hs
narrator:
夜色压在城墙上。
卫兵的脚步由远及近。
//

guard_a:站住！//
```

### 反例
```hs
# 错误：中文角色名
卫兵:
站住！
//

# 错误：用全角冒号
narrator：夜色很深。//

# 错误：对白块里塞选项
narrator:
你要离开吗？
-是的:那就走吧//
//
```

## 2. 选项树（仅在对白块外）

### 规则
- 必须从**行首**开始写 `-` / `--` / `---`…（层数 = `-` 个数）
- 行内若要字面量 `-`，写成 `\-`
- 常见形态：
  - `-选项文案:回复正文//`
  - `-选项文案:>>func_name//`（调用函数，见下节）
  - `-选项文案:>inject_name//`（跳到注入点 `@inject_name`，见下节）
  - `-选项文案:<<回复正文//`（说完后回到上一级选项重选，见下节）
  - `---只有选项文案//`（无回复、无调用）
- `:` 右侧判定（按优先级）：
  1. 以 `>>` 开头 → 函数调用
  2. 以 `<<` 开头 → 回退重选（其后为可本地化回复）
  3. 以单个 `>` + 标识符开头 → 跳转到对应 `@` 注入点
  4. 否则 → 普通回复正文

### 正例
```hs
-这是哪:大牢……//
--我当然知道这里是大牢:>>testfunc//
---该死的哑巴//
-我为什么在这:有人说你是魔女。//
-去问卫兵:>guard_question//
-魔女？我怎么可能是魔女？:<<那……那到底是怎么回事呢？//
```

### 反例
```hs
# 错误：行首有空格
 -这是哪:大牢//

# 错误：把选项写成 speaker
-这是哪:
大牢
//

# 错误：未转义的行内 -
旁白:他打出一记-重拳。//
# 应写作：
旁白写法错误示范请改用 narrator:他打出一记\-重拳。//
```

## 3. 函数调用 `>>name`

### 规则
- 固定范式：出现裸 `>>` 即函数调用（通常写在选项的 `:>>func//`）
- 函数名：`[A-Za-z_][A-Za-z0-9_]*`
- 文本里要写字面量 `>>` 时用 `\>>`

### 正例
```hs
--继续:>>testfunc//
```

### 反例
```hs
# 错误：>> 后面跟中文或空格句子
--继续:>>去问问卫兵//

# 错误：未转义
旁白:屏幕显示 >>ENTER//
# 应：
narrator:屏幕显示 \>>ENTER//
```

---

## 4. 回退 `<<`（重做上一级选择）

### 规则
- 写在选项的 `:<<` 之后：`-文案:<<回复正文//`
- 引擎播完回复后，**退回上一级选项菜单**并重新展示可选分支（顶层 `-` 则重开当前这组选项）
- `<<` 后的正文是普通对白，会进入 `.lines`；可为空：`-文案:<<//`
- 与 `>>`（调用）、`>`（跳转）不同：这是回退，不是前进

### 正例
```hs
-我只是个普通女孩。:<<真的吗？//
--真的。:>rat_question_conversion_2//
--逗你的。:<<啊！！！！！！！！你别靠近我！//
```

### 反例
```hs
# 错误：写成函数或跳转
-回去:>>parent//
-回去:>parent//
```

---

## 5. 跳转 `>name`（到注入点）

### 规则
- 写在选项的 `:>` 之后：`-文案:>name//`
- `name`：`[A-Za-z_][a-zA-Z0-9_]*`，对应剧本中的注入点 `@name`
- **单个** `>`，不要写成 `>>`（`>>` 是函数调用）
- 不是可本地化答复；`.lines` 不收录 `>name` 本身

### 正例
```hs
@guard_question
guard_a:……//
-离开:好。//

@later
narrator:后来……//

-回去问卫兵:>guard_question//
```

### 反例
```hs
# 错误：写成函数调用
-回去:>>guard_question//

# 错误：带 @ 或空格
-回去:>@guard_question//
-回去:> guard_question//
```

---

## 6. 注入点 `@后缀`

### 规则
- **单个** `@` + 非空白后缀，不跨行（如 `@dialog`、`@guard_question`）
- 用作引擎注入点；可被选项 `:>name` 跳转定位
- **不要**与行首终止符 `@@` 混淆
- 不要随手编造无约定的 `@` 标记

### 正例
```hs
@dialog
```

### 反例
```hs
# 错误：中间有空格 / 跨行
@ dialog
@dia
log
```

---

## 7. 终止符 `@@`

### 规则
- **行首**写 `@@`（可带后缀，如 `@@` / `@@end`），整行视为**终止符**
- 表示当前剧本段结束
- **不是**注入点：注入点是单个 `@`（如 `@dialog`）；终止符是行首 `@@`
- 不要缩进；不要写在对白块内部

### 正例
```hs
@guard_question
guard_a:……//
-离开:好。//
@@
```

### 反例
```hs
# 错误：行首有空格
 @@
# 错误：单 @ 是注入点，不是终止符
@end
```

## 8. 宏 `#define`（简单替换）

### 规则
- 顶格一行：`#define name replacement`
- `name`：`[A-Za-z_][A-Za-z0-9_]*`（无参数宏，不做 `FOO(x)`）
- `replacement`：同一行剩余文本（去掉首尾空白）
- 解析前做**整词标识符替换**；可多层（如 `strong` → `str>0` → `ctx.player.strength>0`）
- **不展开**：`#…` 行（含 `#define` 自身与注释）、`''''…''''` Python 块内
- 勿用 speaker / 常用函数名当宏名

### 正例
```hs
#define str ctx.player.strength
#define strong str>0

guard:怎么了？//
-硬闯:你力气够大。//
```

展开后 `strong` → `ctx.player.strength>0`（供条件等标识符位置使用）。

### 反例
```hs
# 错误：行首有空格
 #define str ctx.player.strength

# 错误：参数宏（不支持）
#define max(a,b) ...

# 错误：宏名非法
#define 力气 ctx.player.strength
```

---

## 9. Python 嵌入 `'''' … ''''`

### 规则
- 一对四单引号包裹 Python 代码
- 代码须为合法 Python；常用于定义选项回调等
- 块内**不会**被 `#define` 展开

### 正例
```hs
''''
def testfunc(ctx):
    if ctx.player.strength > 50:
        return ("你是被卫兵抓过来的。", {"卫兵?": ("对", {"好": None})})
    return ("……", {})
''''
```

### 反例
```hs
# 错误：三引号或随意围栏
```python
def testfunc(ctx):
    pass
```
```

---

## 10. 注释

### 规则
- `#` 行注释（`#define` 除外）
- `#【场景】` / `#【动作】` 为带标签注释（可整行）

### 正例
```hs
# 这一段先保留
#【场景】黄昏，青石巷。
#【动作】撑伞，停步
```

## 11. Agent 改稿自检清单

写入前请确认：
1. 所有 speaker 名是否只含字母数字下划线？
2. 每个对白块是否都有结尾 `//`？
3. 选项是否都在块外、且从行首开始？
4. `>>` 是否只跟合法函数名，或已正确转义？
5. `:>name` 跳转是否对应已有 `@name`，且未误写成 `>>`？
6. `:<<` 是否用于「说完回退重选」，且其后文案需要本地化？
7. `#define` 是否顶格、宏名合法，且未遮住 speaker / `>>` 名？
8. 终止符是否行首 `@@`（不要写成单 `@`）？
9. 是否误把选项/中文当成 speaker？
