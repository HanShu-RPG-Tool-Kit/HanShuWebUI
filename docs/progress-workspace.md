# 进度流程原型

“进度流程”是 HanShu 的内容设计工作区，工作区 ID 为 `progress-flow`。任务、章节推进、探索解锁是文档的内容类别。当前阶段先确定作者如何组织阶段、分支和条件，执行规则由后续引擎设计。

## 原型草稿

当前内部草稿暂用 `format: "hanshu.progress-tree"`、`version: 1` 和 `.hflow` 后缀，以 JSON 保存和恢复编辑内容。这些是原型实现细节，不是冻结的文件协议或引擎数据格式；现阶段不做版本迁移、兼容层或专用 Git 合并机制。模型不包含游戏资源 ID 规则、注册表、数据包路径或 Mod 字段。

```json
{
  "format": "hanshu.progress-tree",
  "version": 1,
  "id": "a-stable-document-id",
  "kind": "task",
  "title": { "text": "驿站的约定", "key": "story.station.title" },
  "description": { "text": "设计这段内容的推进过程。" },
  "entry": { "id": "entry", "target": "start" },
  "nodes": {
    "start": {
      "title": { "text": "收到邀请" },
      "description": { "text": "作者对这个阶段的说明。" },
      "branching": "parallel",
      "completion": "continue",
      "children": [
        {
          "id": "accept",
          "target": "prepare",
          "title": { "text": "接受邀请" },
          "trigger": "confirm",
          "conditions": { "mode": "all", "items": [] }
        }
      ],
      "onEnter": [], "onFinish": [], "rewards": []
    },
    "prepare": {
      "title": { "text": "准备出发" },
      "description": { "text": "" },
      "branching": "parallel",
      "completion": "finish",
      "children": [], "onEnter": [], "onFinish": [], "rewards": []
    }
  }
}
```

checkpoint 按稳定 ID 平铺保存，允许独立存在；有序 `children` 暂存连接名称、目标节点与推进条件，画布连线由它派生。可选 `layout.positions` 单独保存各节点的 `{x, y}` 坐标，允许负数；拖动只改变位置，不改变内容或连接。没有手工位置时按图结构初次排列，首次创建、拖动或删除后保留其他节点位置。无限画布的平移与缩放是视图状态，不写入文档或撤销历史。

可选 `logic` 保存合取（`and`）、析取（`or`）节点，`goals` 按 ID 保存独立 Goal 条件节点。Goal 包含名称、说明、条件类型、参数和阶段引用，仅有结果输出、没有输入端口；逻辑节点的输入可接多条线。涉及 Goal 或逻辑节点的连接保存在 `logic.links`，记录 `{id, from, to, port: "input"}`，不套用阶段分支字段。Goal 支持人工标记、累计事件、等待信号、等待阶段和外部条件引用。当前仅编辑声明，不计算真值或绑定可见性、可用性。已移除蕴涵；没有兼容或迁移层。

可选 `layout.groups` 按组 ID 保存 `{name?: "组名称", nodes: [节点 ID]}`。Group 只记录一起移动的节点，不参与流程执行、条件求值或节点层级；名称用于画布整理，包围盒由成员的位置和尺寸即时计算。节点可属于一个 Group，分组至少有两个成员，不支持嵌套组。删除成员或重新分组时清理不足两个成员的旧组，重命名节点同步维护组内引用；保留下来的组名称不丢失。

`entry` 是独立的起点节点，包含稳定 ID 和可为 `null` 的入口连接目标。它不承载 checkpoint 的名称、说明、条件、动作或奖励，也不能改成 checkpoint 或删除；坐标与 checkpoint 一样独立保存。每份新流程初始只有一个起点，作者可以从起点新建并连接 checkpoint，也可以先在空白处自由创建，再设置入口目标。没有旧起点标记格式的兼容或迁移层。

删除 checkpoint 仅移除当前阶段、关联连接及条件引用，后续节点原地保留。如果它是入口目标，就断开入口连接；起点始终保留。“起点下面的树如何提取为任务”及任务的有效结构留待后续设计，草稿不强制 checkpoint 的单父、可达性或无环。

`branching` 描述并行推进、选择一条或按顺序选择的设计意图；`completion` 显式描述继续或结束。当前原型不执行这些声明，独立节点和未完成的叶节点可自由保留。

条件声明支持人工标记、累计事件、等待信号、等待其他阶段和外部条件引用；节点引用放在 `nodeRefs` 中，重命名和删除时统一维护。动作与奖励使用 `{id, reference, params}` 资源引用，编辑器不读取游戏对象或执行脚本。这些字段是可继续讨论的创作协议，不是已经实现的运行时 API。

展示文字使用 `{text, key?}` 明确区分设计原文和可选本地化键。当前 UI 预览原文；没有原文时显示文本键。语言资源、参数化文本及运行时翻译留待后续设计。

## 编辑与保存

- 左侧资源管理器用文件夹与 `.hflow` 文件组织流程，可折叠目录、筛选资源、在目录下新建或导入。资源名称与文档标题、稳定 ID 分开维护。
- 右键资源可重命名、移动、导出或移除；支持拖动文件和文件夹到目录，禁止移入自身或子目录，同目录不可重名。文件夹仅在清空后删除。
- 资源树支持方向键、Enter 打开、F2 重命名、Shift+F10 菜单；新建和重命名在树内输入，Enter 确认、Esc 取消。
- 画布单击选择；双击阶段或分支打开表单弹窗，也支持 Enter / F2。流程信息通过画布标题旁的按钮编辑，不再显示常驻属性面板。
- 弹窗先显示名称、说明等基本内容，动作、奖励与结构设置按需展开。“完成”一次提交、一次撤销；取消、关闭或 Esc 放弃本次编辑。弹窗使用模态对话框，背景不可操作。
- 空白处右键，或打开工具栏的“＋ 节点”菜单，可创建 checkpoint、Goal、合取、析取、转移节点、集线器、网关和注释。右键创建使用鼠标位置，工具栏创建使用当前视野中心。双击空白画布不创建节点。拖动节点调整位置，松开鼠标后保存为一次可撤销的编辑。
- 空白处拖拽框选；Shift / Ctrl / Command 可追加选择。框选同时命中节点与连线；连线支持 Shift 追加多选，可与节点混合。选中多个节点后，使用工具栏、右键菜单或 Ctrl+G 创建 Group；Ctrl+Shift+G 解除 Group。拖动组标题或任一组员会联动移动整个组；显示覆盖组内节点的包围盒，移动时加强边框和底色。一次拖动只记一次撤销，解除分组保留节点位置、内容和连线。
- 双击 Group 标题、聚焦后按 F2 / Enter，或通过右键菜单重命名，在组标题处直接输入。Enter 或失去焦点确认，Esc 取消，空名称不提交；支持中文输入法。名称随草稿保存，重命名可撤销；长名称省略显示并保留悬停提示。
- 按住右键拖动平移无限画布，可从空白、节点、组标题或连线上开始，不受原点和画布边界限制。单击右键仍打开对应菜单；拖动结束不弹菜单。鼠标滚轮以指针所在位置为中心缩放，范围为 20%–250%；同时支持工具栏缩放按钮、“显示全部”和“定位起点”。平移、缩放后的框选、连线、小刀与节点创建使用同一画布坐标。
- 在画布空白处双击，第二次按住并拖动，使用小刀切割连线。显示红色虚线轨迹、小刀图标及待切割连线高亮；松开时一次断开划过的所有连接，Ctrl+Z 一次恢复。Esc、指针取消或窗口失焦放弃切割。切割不删除节点、组或节点内容；普通拖拽仍为框选，节点双击仍打开表单。
- 拖动右侧输出端口到左侧输入端口连线，也支持从输入端口反向拖到输出端口；预览线随鼠标移动，可连接端口高亮，松开到空白处或按 Esc 取消。键盘可依次聚焦两个端口按 Enter / Space 连线。起点与 Goal 仅有输出端口，结束 checkpoint 仅有输入端口。
- 基数与路由：起点出口等同转移 Next，接到一条 checkpoint 或集线器；转移 Parent / Next 各一条（再连替换）；Goals 可接多条 Goal。Checkpoint 之间不能直连，必须经转移（ckpt → Parent → Next → ckpt），也可经集线器 / 网关扇出扇入。普通 checkpoint 仍可扇入扇出到多个转移或逻辑口。颜色只表示类型匹配；集线器↔网关走独立桥接口（珊瑚红），不占用分出 / 汇入。
- 起点重连会替换唯一出口；右键「新建下一节点」会自动创建转移并接好 Parent / Next。重复连接同一对端口会选中已有连接。连接不会重新排列节点。
- 连线只显示曲线，不显示文字或标签。单击曲线选择，Shift 单击追加；按 Delete / Backspace，或右键连线选择“断开连接”，仅移除选中连接和分支内容，两个端点及其他分支原地保留。多选连线时可一次断开全部。曲线支持键盘聚焦、Enter / F2 编辑及 Shift+F10 菜单。连线和断开均保存为一次可撤销编辑。
- 普通连线与连接预览的曲率随端口水平间距调整，近距离不使用固定最小控制柄，向前连接的控制点不交叉；远距离控制柄最多伸出 160 个画布单位。自环保留独立弧线。小刀沿实际显示的曲线路径判断相交。
- 起点有专用菜单与简洁弹窗，可新建并连接第一个 checkpoint、更换入口目标或断开入口；没有阶段字段，删除键无效，菜单删除项禁用。起点可以自由移动，拖动与连接操作可撤销。
- 右键 checkpoint 可新建下一节点、编辑、连接到起点、设置或取消结束标记、删除；新建下一节点自动连接，空白处创建则不自动连接。支持 Shift+F10、方向键与 Esc。
- 逻辑节点使用紫色标题栏和 ∧ / ∨ 符号区分，尺寸 156×76；Goal 使用金色标题栏，尺寸 216×94；checkpoint 尺寸 216×108，起点尺寸 156×62；转移 / 集线器 / 网关 180×108（集线器暖铜标题、网关靛灰标题）。端口颜色跟随类型（Goal 金、checkpoint / 起点出口 / Parent / Next / 分出 / 汇入 / 离开 蓝灰、逻辑紫、桥接珊瑚），转移节点的 Goals / Parent / Next 分别使用对应类型色。只展示名称、端口及一行摘要，详细内容由双击弹窗编辑。节点支持创建、移动、删除、连线及草稿保存。
- 删除键（Delete / Backspace）和右键菜单删除所选项，弹窗删除当前节点；多选含连线时一并断开。起点保留，关联连接和引用被清理，空等待条件会报告问题。一次撤销恢复整次删除的节点、内容、连接和位置。
- 调整分支顺序、重命名 checkpoint、修改连接；重命名同步更新位置、入口目标、连接及节点条件引用。
- 节点编辑区域采用灰色点阵画布、分类标题色条、左右圆形端口、曲线连线与橙色选中边框；长 ID 收在悬停提示中。曲线可直接双击编辑；支持“显示全部”和“定位起点”。样式只作用于节点编辑区域，其余资源管理器和工作区外观保持原样。
- 文档结构视图可直接修改 JSON；结构错误保留为草稿，语法和容器形状恢复后再显示树图。
- 每份文档有会话内撤销/重做，通过主菜单或画布中的 Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 操作；源码连续输入合并为一次编辑。资源目录操作独立于文档历史。
- 条件参数、动作和奖励 JSON，以及节点/分支 ID 修改需要先应用或放弃，再完成弹窗。Ctrl+Enter / Ctrl+S 可完成编辑；尚未提交的修改会在离开页面时提示。
- 本机草稿库使用 `hanshu.progressWorkspace.v1`，原始未完成源码也会保存。读取失败时阻止自动覆盖。
- 导入 `.hflow` / 原生 JSON 文档；导出通过结构校验的树图，或下载未经校验的原始草稿。

校验覆盖必需的独立起点、画布 ID 唯一性、草稿容器、坐标、入口与条件引用、条件声明及资源引用形状。未连接的 checkpoint、共享目标和环不作为草稿错误。尚未定义任务提取、运行时失效条件、分支竞态、提交事务和复杂等待依赖；编辑器不声称能模拟执行。

## 验证

运行 `npm run test:progress` 检查起点不可删除、独立移动、入口连接、画布连线与断开、自由节点创建、逻辑端口、位置保存、单节点删除、引用维护、文本往返和存储。运行 `npm run build`、`npm run lint` 检查应用。

### 画布注释

在画布空白处右键选择「添加注释」，创建不参与流程执行、没有端口的说明块。双击或按 F2 原地编辑标题与多行纯文本，Enter 换行，Ctrl+Enter 确认，Esc 取消；点击外部也会确认。拖动说明块移动，拖动右下角调整尺寸；调整尺寸按钮也支持方向键（Shift 加大步长）。右键可以选择灰蓝、暖灰、灰绿或灰紫，以及删除注释。

注释参与框选和 Group 联动移动。标题、文本、尺寸、颜色保存在 `layout.notes`，位置使用 `layout.positions`，所有修改沿用草稿保存及撤销。注释不进入 checkpoint、Goal、逻辑节点或连接模型。

### 多选删除与智能排版

框选或按住 Shift/Ctrl 多选后，Delete/Backspace 或右键「删除所选」会一起删除 checkpoint、Goal、逻辑、转移、集线器、网关及注释，并清理相关连线；若多选了连线则一并断开。起点始终保留。批量删除/断开是一个撤销步骤。

多选右键「智能排版」只微调已有布局：对齐坐标相近的行与列，对接近等距的阵列统一间距，保持行列顺序与共享列关系。单次移动不超过 32 个画布单位，保留明显分离的结构和悬殊间距，避免新增或加重与其他元素的重叠。不根据流程连接重新排整张图；只调整选中项的位置，内容、连接和 Group 成员不变，支持一步撤销。

### 转移节点

空白画布右键或「＋ 节点」菜单可以创建转移节点。左侧上为 Goals（`input`，可接多条 Goal）、下为 Parent（`input2`，只接一条 checkpoint 或集线器分出）、右侧为 Next（只接一条 checkpoint 或网关汇入）。起点出口与 Next 同色同规则，可接到 checkpoint 或集线器。Checkpoint 之间禁止直连，推进必须走「上级 ckpt → Parent → Next → 下级 ckpt」，也可经集线器 / 网关汇聚。端口颜色与类型一致；连线与拖线预览沿用源端口颜色。Parent / Next / 起点出口再连会替换原有连接。转移节点保存在 `transitions`，连接沿用画布连接记录，支持双击编辑名称/说明、框选、分组、智能排版、批量删除与撤销。当前仅提供结构，不定义运行时推进语义。

### 集线器与网关

- **集线器**（`hubs`）：左侧进入（仅 checkpoint 或起点）；右侧上「分出」到转移 Parent（可多条）；右侧下「桥接」`output2` 专连网关。进入与桥接再连会替换。
- **网关**（`gateways`）：左侧上「汇入」接转移 Next（可多条）；左侧下「桥接」`input2` 专接集线器 `output2`；右侧「离开」到一条 checkpoint。离开与桥接再连会替换。
- 集线器↔网关必须走专用桥接口（右侧↔左侧），不占用分出 / 汇入 / Parent / Next。1:1：同一集线器最多一条桥接出，同一网关最多一条桥接入；新连会清掉双方旧桥接边。网关不能连回集线器。
- 桥接端口使用独立珊瑚红；其余端口仍为 checkpoint 蓝灰。当前仅编辑结构，不定义运行时语义。
