# 进度流程原型

“进度流程”是 HanShu 的内容设计工作区，工作区 ID 为 `progress-flow`。当前阶段先确定作者如何组织阶段、分支和条件，执行规则由后续引擎设计。

**流程模型与信号语义、表达能力分析**见 [进度流程模型](#progress-flow-model)。

## 原型草稿

当前内部草稿暂用 `format: "hanshu.progress-tree"`、`version: 1` 和 `.hflow` 后缀，以 JSON 保存和恢复编辑内容。这些是原型实现细节，不是冻结的文件协议或引擎数据格式；现阶段不做版本迁移、兼容层或专用 Git 合并机制。模型不包含游戏资源 ID 规则、注册表、数据包路径或 Mod 字段。

```json
{
  "format": "hanshu.progress-tree",
  "version": 1,
  "id": "a-stable-document-id",
  "entry": {
    "id": "entry",
    "target": "start",
    "title": { "text": "驿站的约定" },
    "description": { "text": "设计这段内容的推进过程。" }
  },
  "nodes": {
    "start": {
      "title": { "text": "收到邀请" },
      "description": { "text": "作者对这个阶段的说明。" }
    }
  },
  "ends": { "finish": {} }
}
```

checkpoint 按稳定 ID 平铺保存，只含名称与说明（`FlowText` 无 `key`）；流程终点用 `ends` 节点（仅输入，checkpoint 激活出可多线连入）。阶段之间经变迁与 `logic.links` 连接，不再使用 `children` 直连。可选 `layout.positions` 单独保存各节点的 `{x, y}` 坐标，允许负数；拖动只改变位置，不改变内容或连接。没有手工位置时按图结构初次排列，首次创建、拖动或删除后保留其他节点位置。无限画布的平移与缩放是视图状态，不写入文档或撤销历史。

可选 `logic.links` 保存 Goal / Predicate / 变迁之间的画布连线（`{id, from, to, port, fromPort?}`）。`goals` / `predicates` 按 ID 保存独立条件节点。合取 / 析取逻辑节点、蕴涵、集线器、网关、流程 `kind`，以及 checkpoint 上的 `children` / `branching` / `onEnter` / `onFinish` / `rewards` 均不在当前格式中；解析也不兼容旧草稿。

可选 `layout.groups` 按组 ID 保存 `{name?: "组名称", nodes: [节点 ID]}`。Group 只记录一起移动的节点，不参与流程执行；名称用于画布整理，包围盒由成员的位置和尺寸即时计算。节点可属于一个 Group，分组至少有两个成员，不支持嵌套组。

`entry` 是独立的开始节点：稳定 ID、入口目标，以及整张图的 `title` / `description`。它不承载 checkpoint 的完成标记，也不能改成 checkpoint 或删除；坐标与 checkpoint 一样独立保存。双击开始节点只编辑图名称与说明；出口连线在画布上操作。

文档根上的 `id` 是作者可控的稳定文档身份（默认 UUID，校验非空且 ≤200），**允许修改**，且不会改写图内节点引用；它与资源树里的文件名、内部资源键不是同一事物。文件名、文档 ID、创建/修改时间在资源管理器右键「属性」中查看与编辑。

## 编辑与保存

- 左侧资源管理器按九个顶层分类组织资源：**脚本**、**进度**、**故事流程**、**演员**、**声誉**、**区域**、**导航器**、**商店**、**礼包**（各分类下可有文件夹）。「脚本」下内置二级分类 **目标定义**（稳定、不可重命名/移动/删除，其下仍可建普通文件夹），其内另有虚拟只读文件夹 **内置**（含 `core:dialogue_choice` / `core:manual` / `core:counter` 等只读样例脚本，不落盘；进度收集目标定义时始终计入，工程脚本同 kind 可覆盖）。并可新建 / 导入 **`.py`** 脚本（主区用 Python 编辑器打开）。「进度」可新建 / 导入 **`.progress`**（委托表单：目标种类来自目标定义脚本）。「导航器」可新建 / 导入 **`.nav`**（导航点 JSON：`position` 固定坐标或 `entity` 绑定实体；对齐引擎 NavigationPoint，不含 datapack 路径 / 资源 id）。「礼包」可新建 / 导入 **`.kit`**（JSON：名称；可选 `extends` 单父继承、`includes` 组合；可选 `tags` 游戏标签 string[]——类似 MC Tag 的成员声明，引擎可查询，**继承与父并集去重、组合不并入宿主**，空则不写入；可选 `params` 超参数 / `modifiers` 修饰器，详见应用内帮助与 `hanshu.kit.expr` V1；物品 ItemStack `{id,count,components,display?}`——`display` 仅编辑器展示快照，附 `snapshotOf` 指纹（id + components 的 FNV-1a，不含 count），与当前数据不一致即视为过期：tooltip 改由 WebUI 近似渲染（名称/稀有度/附魔/描述/无法破坏，未识别组件只计数），图标保留但加角标；可从桌面拖入模组导出的 **`.itemstack`** 文件追加/替换物品；随机池 `pools[{rolls, entries[{weight, items}]}]`、药水效果 `effects[{id, amplifier, duration(秒,0=无限), particles}]`、指令、经验 `{kind: levels|points, amount}`、领取反馈 `feedback{message,title,subtitle,sound}`、内联脚本；可选块为空时不写入文件；居中双栏表单）。`.hflow` 树图流程仅能在「故事流程」中新建与导入；其余分类暂只支持文件夹占位，供后续扩展。

  **工程目录**：进度与剧本共用同一工程包根。打开/新建工程后，进度文档落在 `src/progress/`、`src/story/`、`src/navigator/`、`src/gift/`、`src/script/`（普通脚本 `.py`）、`src/goal/`（「目标定义」二级分类下的 `.py`，与 script 平级、不嵌套）。内置目标定义脚本来自仓库 `src/workspaces/progress/builtinGoals/*.py`（构建时打进包，虚拟只读展示，不写入工程）。编辑会即时写入共享工程会话；在进度区「保存」/Ctrl+S 即可整包落盘，无需回到剧本区。未打开工程时进度区只读提示。旧的整库 `hanshu.progressWorkspace.v1` 会在打开工程时迁入源文件后删除；页条等 UI 状态改存 `hanshu.progressUi.v1`。旧草稿未带分类字段时加载为「故事流程」。资源名称与文档标题、稳定 ID 分开维护。

  **本地化**：`.progress` / `.hflow` / `.nav` / `.kit` 的玩家可见文案与 `.hs` 同布局——源文件存语义键，译文在 `assets/<locale>/lang_progress|lang_hflow|lang_nav|lang_kit/….lang`。键为文档内相对路径（如 `name`、`description`、`entry.title`、`label`、`feedback.message`），不含文件名；改文件名时搬迁对等 `.lang`。底部语言切换与剧本共用 `hanshu.locale`。作者备注、画布注释、礼包音效 id / 标签 / 指令不进本地化。打开旧明文稿时自动收成语义键并把原文灌入当前语言。
- 主区按 VS Code 方式划分**编辑组**，每组有自己的**文档页条**（流程 / 脚本 / 礼包共用）：打开即加入、可拖拽排序；右键可固定、关闭、关闭其他页、关闭右侧页、关闭所有页；固定页跳过关闭，须先取消固定；中键关闭未固定页。
  - 最多两组。未拆分时，把页拖到编辑区左 / 右 / 上 / 下边缘即移过去并拆分（组里只剩这一页时改为复制）；右键「向右拆分 / 向下拆分」则复制一份到新组。
  - 已拆分时，页可在两组页条间拖动，或拖到另一组的内容区；右键另有「移到另一侧」「合并拆分」。某组关空即自动收起拆分。
  - 资源管理器打开的文档进入焦点组；同一文档可同时开在两组，画布交互只在焦点组生效。分割线 1px，可拖动，双击恢复对半。
  - 主组状态在根上（`openKeys` / `activeKey` / `pinnedKeys`），第二组与方向、比例、焦点存于 `split`；旧草稿的 `splitKey` 读取时自动迁移。
- 右键资源可打开属性、重命名、移动、导出校验通过的树图、下载原始草稿或移除；支持拖动文件和文件夹到目录，禁止移入自身或子目录。文件夹是资源树的**视图归属**（存于 `hanshu.progressUi.v1` 的 `folders` / `documentFolders`），磁盘与 `lang_*` 仍按文件名扁平；**同一分类内文件名全局唯一**（跨文件夹也不许重名），文件夹名仅同级唯一。文件夹仅在清空后删除。
- 可从系统资源管理器拖入或多个文件粘贴到分类/文件夹（含「目标定义」）：脚本接受 `.py`，礼包接受 `.kit`，故事流程接受 `.hflow` / `.json`；不匹配扩展名的文件会跳过并提示。
- 资源树支持 Ctrl/Command 追加多选、Shift 范围多选、Ctrl+A 全选；Delete / Backspace 或右键「移除所选」批量删除流程与空文件夹。方向键、Enter 打开、F2 重命名、Shift+F10 菜单；新建和重命名在树内输入，Enter 确认、Esc 取消。
- 画布单击选择；双击阶段或开始节点打开表单弹窗，也支持 Enter / F2。图名称 / 说明经开始节点编辑；文档 ID 与文件名在资源管理器「属性」中修改。
- 弹窗先显示名称、说明等基本内容，动作、奖励与结构设置按需展开。“完成”一次提交、一次撤销；取消、关闭或 Esc 放弃本次编辑。弹窗使用模态对话框，背景不可操作。
- 空白处右键，或打开工具栏的“＋ 节点”菜单，可创建 checkpoint、Goal、Predicate、线性/条件/差分/合并/交换变迁和注释。右键创建使用鼠标位置，工具栏创建使用当前视野中心。双击空白画布不创建节点。拖动节点调整位置，松开鼠标后保存为一次可撤销的编辑。
- 空白处拖拽框选；Shift / Ctrl / Command 可追加选择。框选同时命中节点与连线；连线支持 Shift 追加多选，可与节点混合。选中多个节点后，使用工具栏、右键菜单或 Ctrl+G 创建 Group；Ctrl+Shift+G 解除 Group。拖动组标题或任一组员会联动移动整个组；显示覆盖组内节点的包围盒，移动时加强边框和底色。一次拖动只记一次撤销，解除分组保留节点位置、内容和连线。
- 双击 Group 标题、聚焦后按 F2 / Enter，或通过右键菜单重命名，在组标题处直接输入。Enter 或失去焦点确认，Esc 取消，空名称不提交；支持中文输入法。名称随草稿保存，重命名可撤销；长名称省略显示并保留悬停提示。
- 按住右键拖动平移无限画布，可从空白、节点、组标题或连线上开始，不受原点和画布边界限制。单击右键仍打开对应菜单；拖动结束不弹菜单。鼠标滚轮以指针所在位置为中心缩放，范围为 20%–250%；同时支持工具栏缩放按钮、“显示全部”和“定位起点”。平移、缩放后的框选、连线、小刀与节点创建使用同一画布坐标。
- 在画布空白处双击，第二次按住并拖动，使用小刀切割连线。显示红色虚线轨迹、小刀图标及待切割连线高亮；松开时一次断开划过的所有连接，Ctrl+Z 一次恢复。Esc、指针取消或窗口失焦放弃切割。切割不删除节点、组或节点内容；普通拖拽仍为框选，节点双击仍打开表单。
- 拖动右侧输出端口到左侧输入端口连线，也支持从输入端口反向拖到输出端口；预览线随鼠标移动，可连接端口高亮，松开到空白处或按 Esc 取消。键盘可依次聚焦两个端口按 Enter / Space 连线。起点与 Goal 仅有输出端口；**结束**节点仅有输入端口（自 checkpoint 激活出连入，可多线）。
- 基数与路由：起点出口等同转移 Next，接到一条 checkpoint ；转移 Parent / Next 各一条（再连替换）；Goals 可接多条 Goal。Checkpoint 之间不能直连，必须经转移（ckpt → Parent → Next → ckpt）。普通 checkpoint 仍可扇入扇出到多个转移口。颜色只表示类型匹配。
- 起点重连会替换唯一出口；右键「新建下一节点」会自动创建转移并接好 Parent / Next。重复连接同一对端口会选中已有连接。连接不会重新排列节点。
- 连线只显示曲线，不显示文字或标签。单击曲线选择，Shift 单击追加；按 Delete / Backspace，或右键连线选择“断开连接”，仅移除选中连接和分支内容，两个端点及其他分支原地保留。多选连线时可一次断开全部。曲线支持键盘聚焦、Enter / F2 编辑及 Shift+F10 菜单。连线和断开均保存为一次可撤销编辑。
- 普通连线与连接预览的曲率随端口水平间距调整，近距离不使用固定最小控制柄，向前连接的控制点不交叉；远距离控制柄最多伸出 160 个画布单位。自环保留独立弧线。小刀沿实际显示的曲线路径判断相交。
- 起点弹窗只编辑图名称与说明；新建/连接/断开出口在画布右键菜单与连线手势中完成。起点没有阶段字段，删除键无效，菜单删除项禁用。起点可以自由移动，拖动与连接操作可撤销。
- 右键 checkpoint 可新建下一节点、编辑、连接到起点、设置或取消结束标记、删除；新建下一节点自动连接，空白处创建则不自动连接。支持 Shift+F10、方向键与 Esc。
- Goal 使用金色标题栏，尺寸 216×94；Predicate 同尺寸；checkpoint 尺寸 216×108，起点尺寸 156×62；变迁节点 180×108（交换随槽数增高）。端口颜色跟随类型（Goal/Predicate 金、checkpoint / 起点出口 / Parent / Next 蓝灰）。只展示名称、端口及一行摘要，详细内容由双击弹窗编辑。节点支持创建、移动、删除、连线及草稿保存。
- 删除键（Delete / Backspace）和右键菜单删除所选项，弹窗删除当前节点；多选含连线时一并断开。起点保留，关联连接和引用被清理，空等待条件会报告问题。一次撤销恢复整次删除的节点、内容、连接和位置。
- 调整分支顺序、重命名 checkpoint、修改连接；重命名同步更新位置、入口目标、连接及节点条件引用。
- 节点编辑区域采用灰色点阵画布、分类标题色条、左右圆形端口、曲线连线与橙色选中边框；长 ID 收在悬停提示中。曲线可直接双击编辑；支持“显示全部”和“定位起点”。样式只作用于节点编辑区域，其余资源管理器和工作区外观保持原样。
- 结构错误时在主区直接编辑源码；语法和容器形状恢复后自动回到画布。
- 每份文档有会话内撤销/重做，通过主菜单或画布中的 Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 操作；源码连续输入合并为一次编辑。资源目录操作独立于文档历史。
- 条件参数、动作和奖励 JSON，以及节点/分支 ID 修改需要先应用或放弃，再完成弹窗。Ctrl+Enter / Ctrl+S 可完成编辑；尚未提交的修改会在离开页面时提示。
- 本机草稿库使用 `hanshu.progressWorkspace.v1`，原始未完成源码也会保存。读取失败时阻止自动覆盖。
- 导入 `.hflow` / 原生 JSON 文档；导出通过结构校验的树图，或下载未经校验的原始草稿。

校验覆盖必需的独立起点、画布 ID 唯一性、草稿容器、坐标、入口与条件引用、条件声明及资源引用形状。未连接的 checkpoint、共享目标和环不作为草稿错误。尚未定义任务提取、运行时失效条件、分支竞态、提交事务和复杂等待依赖；编辑器不声称能模拟执行。

## 验证

运行 `npm run test:progress` 检查起点不可删除、独立移动、入口连接、画布连线与断开、自由节点创建、变迁端口、位置保存、单节点删除、引用维护、文本往返和存储。运行 `npm run build`、`npm run lint` 检查应用。

### 画布注释

在画布空白处右键选择「添加注释」，创建不参与流程执行、没有端口的说明块。双击或按 F2 原地编辑标题与多行纯文本，Enter 换行，Ctrl+Enter 确认，Esc 取消；点击外部也会确认。拖动说明块移动，拖动右下角调整尺寸；调整尺寸按钮也支持方向键（Shift 加大步长）。右键可以选择灰蓝、暖灰、灰绿或灰紫，以及删除注释。

注释参与框选和 Group 联动移动。标题、文本、尺寸、颜色保存在 `layout.notes`，位置使用 `layout.positions`，所有修改沿用草稿保存及撤销。注释不进入 checkpoint、Goal、Predicate、变迁或连接模型。

### 多选删除与智能排版

框选或按住 Shift/Ctrl 多选后，Delete/Backspace 或右键「删除所选」会一起删除 checkpoint、Goal、Predicate、变迁及注释，并清理相关连线；若多选了连线则一并断开。起点始终保留。批量删除/断开是一个撤销步骤。

多选右键「智能排版」只微调已有布局：对齐坐标相近的行与列，对接近等距的阵列统一间距，保持行列顺序与共享列关系。单次移动不超过 32 个画布单位，保留明显分离的结构和悬殊间距，避免新增或加重与其他元素的重叠。不根据流程连接重新排整张图；只调整选中项的位置，内容、连接和 Group 成员不变，支持一步撤销。

### 转移节点

空白画布右键或「＋ 节点」菜单可以创建转移节点。左侧上为 Goals（`input`，可接多条 Goal）、下为 Parent（`input2`，只接一条 checkpoint ）、右侧为 Next（只接一条 checkpoint ）。起点出口与 Next 同色同规则，可接到 checkpoint 。Checkpoint 之间禁止直连，推进必须走「上级 ckpt → Parent → Next → 下级 ckpt」。端口颜色与类型一致；连线与拖线预览沿用源端口颜色。Parent / Next / 起点出口再连会替换原有连接。转移节点保存在 `transitions`，连接沿用画布连接记录，支持双击编辑名称/说明、框选、分组、智能排版、批量删除与撤销。当前仅提供结构，不定义运行时推进语义。
