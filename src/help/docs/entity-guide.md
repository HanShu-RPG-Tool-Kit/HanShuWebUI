# 实体库：模板、快照与在线预览

在进度流程的资源管理器「实体库」中新建或导入 `.entity`。工程路径 `src/entities/<名称>.entity`；文件名是扁平模板 ID，视图文件夹只用于整理。保存仍使用工程服务的文件事务、版本检查和协作草稿，不会让浏览器直接改工程目录。

## 编辑

左侧展示在线画面或本机快照，右侧编辑实体类型、标签、外观/行为、基础属性、内嵌装备及完整 TNBT JSON 数据。最大生命、基础攻击力和移动速度为空时沿用实体默认值。名称卡片编辑普通文本；复杂名称文本可在完整数据树中编辑，读取不会自动覆盖它。

装备保存内嵌原版物品数据，不提供 `.it` 引用，包含 `rpgtoolkit:item_template` 绑定的数据会被拒绝。未由常用卡片覆盖的字段由完整数据树保留。实体库不进行模板同步，不扫描已有实体。

「捕获游戏中指向的实体」请求 MC 从服务端读取完整实体 NBT，需要原版管理员查询权限。默认剔除身份、位置、运动等状态，并解除装备模板绑定。过滤只在捕获时执行，开发接口保留自定义策略，第一版没有用户配置入口。不支持玩家和乘客/坐骑组合。捕获期间文档被修改或关闭时，不用迟到结果覆盖当前草稿。

## 在线预览与快照

连接 [游戏开发服务器](#game-dev-server) 并进入世界后，点击「开启在线预览」。MC 临时使用专用预览画面并串流到 WebUI，左键拖动旋转、右键平移、滚轮缩放。可选择 idle/walk/run/attack/spin 动画；「刷新预览」应用当前草稿，「自动取景」恢复平移/缩放。预览使用独立客户端实体，不在游戏世界生成实体。

取景优先使用实体渲染器的 AABB，按旋转与俯仰投影后的范围适配视窗。渲染器未正确申报模型范围时仍可能超出边界，允许手动缩放。部分实体不具备对应动画，复杂模组实体需实机检查。

预览与已有游戏串流互斥。开启后 MC 窗口会临时隐藏并保持渲染；关闭后恢复窗口。切换文件/工作区或断开游戏连接会关闭预览，无保活 15 秒也会回收。不自动抢占另一窗口的预览。

预览开始后自动将稳定帧缓存为 PNG。快照按实体数据指纹存客户端 IndexedDB，最多 200 项，不写入 `.entity`、工程资产或 PAK；离线仍可浏览本机已有快照。编辑后提示快照待更新，重新预览即可刷新。快照是当前 MC 模组和资源包环境的展示结果，不是实体配置。

## 导出与游戏端

导出到服务端 PAK 的 `entities/<名称>.entity`，继续使用 TNBT JSON，不转成无类型 JSON。Mod 通过 `EntityTemplates` 查询模板和标签、生成新实体；标准入口 `/rt entity` 提供可搜索、翻页的服务端箱子菜单，点击生成；`/rt entity spawn <模板>` 在指令位置生成。

每次生成创建新 UUID，并使用调用方指定的位置，不建立模板绑定。模板改动只影响后续生成。游戏端代码与指令需要更新后的 Mod。

## 开发验证

`test:entity`：模型、目录、导出平面和帧校验；`test:entity:ui`：模拟 MC 传输下的 RPSF 绘制、输入、快照、捕获、关闭及只读；`test:entity-project:ui`：真实工程服务中的新建、保存、重开和权限。Mod 提供实体生成 GameTest 和取景数学 JUnit。浏览器模拟帧与服务端 GameTest 不代表原生 MC 图形客户端渲染已经验收。
