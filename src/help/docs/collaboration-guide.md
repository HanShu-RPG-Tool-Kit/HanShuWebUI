# 连接与协作

## 本机打开或新建工程

使用「文件 → 打开工程… → 打开本机工程…」选择目录；新建使用「文件 → 新建工程…」，填写名称并选择保存位置。本机服务负责工程读写，网页和桌面编辑器都通过它保存内容。Web 调试也需要启动本机服务，通常运行 `npm run dev`。

可信本机入口自动以内置 **Admin** 登录，无需填写密码。Admin 不能远程登录；其他设备必须使用普通账号。

## 创建账号与分享

1. 在本机打开工程，展开协作浮球，进入「用户管理」。
2. 填写用户名、昵称、初始密码，选择当前工程的「可编辑」或「只读」权限，创建用户。
3. 打开「文件 → 分享工程…」，开启局域网共享并复制工程分享链接。
4. 对方在浏览器打开链接，用用户名和密码登录。

用户名用于登录，不区分大小写，须为 3–40 位英文字母、数字、点、下划线或短横线；昵称用于头像与成员列表展示，可以重复。密码至少 10 个字符。没有公开注册入口，分享链接本身不授予权限。

只有本机 Admin 可以管理用户。管理面板可修改当前工程权限、重置密码和启停账号。重置密码或停用会使该账号现有登录失效。同一本机服务管理的多个工程共用账号，但每个工程需分别授权。

其他设备无法访问时，检查双方网络与分享地址；Windows 可在分享面板请求允许专用网络的防火墙访问，系统会要求确认。局域网 HTTP 分享没有传输加密；互联网接入需另外配置 HTTPS，并将反向代理指向共享监听。

## 最近连接与重新登录

已有服务地址也可通过「文件 → 连接其他服务器…」连接。「最近连接」保留最近 12 条工程地址、工程名称和用户名，点击即可填回地址与用户名，也可移除记录；不会保存密码或会话令牌。设备 IP 或共享端口变化时，需要使用新的分享地址。

登录令牌只保存在当前页面内存。刷新页面、重启服务或会话失效后需要重新登录；普通账号每次登录最长 8 小时。关闭共享会断开普通协作会话，账号与工程授权保留。

## 查看成员与处理修改

协作浮球可以自由拖动，点击展开后查看成员与「修改」。成员按账号分组，分别显示各窗口正在查看的文件与编辑状态；一个窗口可以保留多个文件的草稿。头像的「编辑中」表示编辑意图，不代表持续独占文件。

进度表单的修改会自动提交；剧本等文件草稿使用「保存修改」或 `Ctrl+S` 提交，皮肤编辑按相应操作提交。服务端校验权限和版本，保存失败不会直接覆盖其他人的内容。失败或待确认结果在「修改」中处理。

### 放弃冲突修改并同步修改

在协作悬浮窗的「修改」页点击同名按钮并确认后，系统会：

1. 先查询结果未知的提交；仍不能确认时停止，保留草稿，避免重复执行。
2. 放弃与服务器冲突的修改。普通文件按关联资源组处理；进度和皮肤条目尽量按字段保留互不冲突的修改。
3. 提交其余可提交的修改，再同步服务器状态。受到丢弃影响的编辑撤销记录会重置。

这不是“丢弃全部本地内容”。如果网络、权限、写权占用或新的冲突使操作无法完成，剩余草稿与失败记录会保留，并提示未完成。需要保留冲突内容时，先使用提交记录的版本对照或备份导出。

清除浏览器站点数据会删除本地草稿和待处理记录；临时会话失效本身不会删除这些内容。重新登录原账号后，可以恢复该窗口已有的待处理记录。
