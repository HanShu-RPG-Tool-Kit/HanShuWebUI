# 商店模板（.shop）

本页规范 WebUI 的商店模板与编辑方式。游戏性工作区「商店」分类创建和导入 `.shop`，源文件保存于 `src/shop/<文件名>.shop`。文件夹遵循[资源分类与共享组织](#resource-organization)，读写、只读权限、冲突与保存遵循[多人协作编程指南](#collaboration-programming)。当前提供模板编辑；游戏交易执行与实例管理不在本次实现范围内。

## 模板与实例

商店模板定义名称、库存主体类型、商店条件组、商品条目、超参数、修饰器和有序脚本列表。模板不提供继承或组合，不保存具体主体实体、运行库存或实例参数值。

组合属于商店实例的能力。实例引用一个或多个模板，每次引用独立传入超参数、绑定具体主体实体。同一模板可在不同实例或同一实例的不同引用中使用不同参数。实例管理的约束如下，本文不定义其实例文件格式：

- 保留每份模板的名称、条件组、条目表及模板边界，不将多个模板展开成一张无来源的表。
- 相同商品、相同局部条目 ID 默认各自保留，不自动合并或覆盖。组合后的条目身份由「模板引用身份 + 条目 ID」确定；同一模板的多次引用也必须能够区分。
- 每次模板引用的超参数、修饰器和脚本作用域相互独立；不把同名定义并入全局命名空间。

## 库存主体

`stockSubject` 只声明类型：`infinite`（无限库存）、`player`（玩家）、`world`（世界）、`server`（服务器）、`game`（游戏）、`npc`（商人 NPC）。具体实体由实例管理。游戏范围可以跨 BC 子服；服务器范围指一个具体服务器，二者不能合并。

同一个库存主体同时承担收款方与供货方。无限库存作为专门类型提供无限供货和接收支付的语义；不在模板里模拟余额，也不拆成两个主体。

## 两层条件

商店级 `visibility` 与 `availability` 是两个独立条件组，复用单进度任务的任务、对话、求值条件编辑方式；不引入任务专属的重复周期条件。

商品级同名字段是表达式字符串，在条目表单中直接展示，也可在表格单元格内编辑，允许引用本模板超参数和修饰器，采用[表达式标准 V1](#kit-expr)。空字符串表示没有额外条件。商店条件组与商品表达式分别建模和编辑，WebUI 不将二者改写或拼接为一个 AND 表达式，也不推导统一条件树。可见性与可用性是不同职责。

## 商品条目与物品

每个商品条目拥有模板内唯一、非空且稳定的 `id`。调整顺序、修改支付或获得内容不改变 ID；数组顺序即展示顺序。

商品条目、商店条件组、超参数、修饰器和脚本在同一页面编辑。商品区域可切换表单或表格视图：表单以交易目录选择当前条目；表格每行是一笔完整交易，支付与获得各自的单元格列出全部物品及数量。点击物品单元格的“编辑物品详情”切到该条目的表单，编辑物品引用、组件、数量与修饰器；表达式可直接在表格单元格输入。两种视图共用选择、排序、增删和草稿数据，切换不会丢失修改或改变条目 ID。视图选择不写入 `.shop`。

`payment` 是支付内容列表，`goods` 是获得内容列表。一次交易按整份列表描述支付和获得，列表内全部参与，没有任选一种支付的隐含语义。

每项复用 kit 的物品结构与数量语义：链接物品库时为 `item`（`.item` 文件名去后缀）+ `count`；内嵌 ItemStack 时为 `id` + TNBT `components` + `count`，不是另造一个 `itemstack` 包装字段。物品行支持拖入 `.item`、`.itemstack`、组件编辑以及数量修饰器 `mods.count`。数量为非负整数，修饰器求值和取整规则与 kit 一致。

不定义虚拟物品类型。每个支付或获得项目都必须具有 item 或内嵌 ItemStack。用户需要虚拟资源时自行通过脚本实现；WebUI 不提供虚拟余额、虚拟物品选择器或默认交易钩子。

## 超参数、修饰器和脚本

`params`、`modifiers` 使用 kit 的声明格式和编辑器，商店默认均为空，不带礼包专属参数。预览值仅留在编辑器会话中，不写入模板。数量可通过 ƒ 绑定修饰器。

`script` 是有序 `{ref}` 数组，引用工程内脚本的完整规范路径（如 `src/script/common/trade.py`），同一引用不重复绑定。WebUI 可添加、排序、移除引用；脚本本体仍由脚本资源管理。此处仅规定引用与作用域，不承诺交易钩子、注入 API、执行时机或回滚机制；这些需要游戏侧另定契约。没有新增 `shop` 脚本类型，也不把商店脚本当作礼包脚本执行。

## 文件示例

```json
{
  "format": "hanshu.shop",
  "version": 1,
  "id": "village-trader",
  "name": "name",
  "stockSubject": "npc",
  "visibility": [],
  "availability": [],
  "params": [{"id":"priceScale","kind":"float","default":1,"hint":"价格倍率"}],
  "modifiers": [{"id":"price","label":"价格","expr":"x * priceScale"}],
  "script": [],
  "entries": [{
    "id": "bread",
    "payment": [{"id":"minecraft:emerald","components":{},"count":2,"mods":{"count":"price"}}],
    "goods": [{"item":"面包","count":3}],
    "visibility": "",
    "availability": ""
  }]
}
```

`name` 是本地化语义键，名称存于 `assets/<locale>/lang_shop/<文件名>.lang`，新建时以文件基名播种译文。模板 ID、条目 ID、物品引用、脚本路径、表达式、超参数标识符和修饰器标识符不参与本地化。商品展示使用 kit 的物品展示快照，不额外保存虚拟图标。

导出前校验模板结构、重复条目 ID、物品内容和引用。商店源文件输出到 PAK 的 `shop/` 服务端平面，语言资源使用共享平面。导出配置不表示游戏侧已实现交易运行时。
