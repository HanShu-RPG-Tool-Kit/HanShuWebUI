# 欢迎使用汉书

汉书（HanShu）是一套面向 RPG 内容创作的工具。可以从顶栏切换工作区：

| 工作区 | 用途 |
| --- | --- |
| 剧本编辑器 | 撰写 `.hs` 剧本，管理资源与配音相关文件 |
| 进度流程 | 故事流程画布、目标脚本与礼包（`.kit`） |
| 皮肤管理器 / 实时预览 | Minecraft 皮肤相关工具 |

## 从这里开始

- [.hs 语法说明](#hanshu-syntax)：剧本正式语法
- [.char 角色卡语法](#char-syntax)：角色槽位文本（本地化 / 配音）

- [导出 PAK](#export-pak)：编译产物与 client / server / shared 分包
