# 地图模板与导航（.level / .nav）

本页是 WebUI 侧的地图数据模型与编辑约定，对应 Mod 侧 RPGToolKit Level 模型 v3。**编辑侧不一定与运行时一一对应，但编译产物必须对齐**。

## 概念

- `level` 指世界/地图的数据模型，不是 `net.minecraft.world.level.Level`。
- 一个 MC 维度就是一个实例；维度存档自己保存「绑定了哪个地图模板」。
- 模板只描述内容（区域、地标），不持有维度、玩家或运行态。
- 不做到达判定：导航只给方向和距离。

## 资源树

「地图」是唯一的地图分类：

```
地图
├─ 地图模板   .level（区域 + 地标）
└─ 导航器     .nav
```

- **地图模板**：源文件 `src/level/<模板名>.level`；模板名（去后缀）就是模板 ID。地标写在模板里，不再有单独的静态导航器视图。
- **导航器**：源文件 `src/navigator/<名称>.nav`。只记录要追踪的地标，坐标在地图模板里。合法 `.nav` 不写入 PAK。

## 先用编辑器完成区域设置

1. 在地图模板中创建或选中体积。拖动边角改变范围，拖动绿色高度控制点改变上下边界；精确坐标放在「范围与高度」。
2. 切到「环境与音乐」，选择要改变的内容，再启用它。雾可以从清晨、洞穴或流动雾开始，随后用颜色和距离滑块继续调整，预设不是限制。
3. 先决定雾是「玩家进入后改变环境」还是「有边界的空间雾」。距离图说明开始和完全遮蔽的位置；空间雾需要有限高度，具体光照和纹理在游戏画面中确认。
4. 天空和滤镜从效果列表中添加，再调整颜色、强度和顺序；音乐从曲目列表中选择。参数旁的说明解释用途和单位，不需要填写 JSON。
5. 点击固定在面板底部的预览按钮检查效果，应用后用 Ctrl+S 保存。停止预览恢复原环境；预览本身不保存、不发布。

网页参数区与游戏内属性区均连续滚动。游戏内可拖动右侧滚动条，悬停控件查看用途说明；滚动参数区不会推拉世界镜头。对象列表和范围属性也使用滚动，不需要翻页。

「制作自定义着色器」是制作新效果的进阶入口。默认先显示可调参数，控件类型和变量定义折叠收起；GLSL、渲染步骤与原始定义用于资源开发。日常使用现有效果无需进入这些页面。自定义后处理的缓冲图和处理步骤、贴图采样与边缘处理均可通过控件设置。

未知扩展键由脚本或附属功能解释，编辑器保留其类型与嵌套数据，不擅自给它们赋予业务含义。雾、天空、滤镜和音乐使用上面的专用面板。

## .level 作者格式（供格式对接与排错）

```json
{
  "tags": ["demo:hub"],
  "regions": [
    {
      "id": "spawn",
      "areas": [
        {"x": [32, 47], "z": [32, 47], "y": [60, 90]},
        {"shape": "circle", "center": [40, 40], "radius": 8, "y": "all"}
      ],
      "custom_data": {}
    }
  ],
  "landmarks": [
    {
      "id": "old_tower",
      "kind": "rpgtoolkit:pos",
      "param": {"x": 40, "y": 72, "z": 40},
      "custom_data": {
        "rpgtoolkit:display_name": "old_tower.display_name",
        "rpgtoolkit:display_icon": "minecraft:compass",
        "rpgtoolkit:display_max_distance": 256
      }
    }
  ],
  "custom_data": {}
}
```

- 区域 `areas` 至少 1 个、最多 256 个；`shape` 可省略，按字段推断：`x`/`z` = 矩形，`center`/`radius` = 圆，`points` = 多边形。
- `y` 为 `"all"` 或 `[min, max]`。
- 子对象 `id` 只在本模板内唯一，不能包含 `$ \ / : * ? " < > |`。
- `tags` 与礼包/商店同一套规范化（去首尾空白、NFC、大小写不敏感去重）。
- `custom_data` 保留为作者 JSON 对象。已有功能用中文属性表单编辑；脚本、附属功能定义的其他键放在默认折叠的「高级扩展数据」。随意增加一个键不会自动产生对应的游戏功能。

## 编译

一个 `.level` 编译成多个运行时文件：

| 产物 | 内容 |
| --- | --- |
| `levels/<模板>.json` | `{ tags, custom_data }` |
| `regions/<模板>$<区域 id>.json` | `{ level, areas, music?, environment?, custom_data? }` |
| `landmarks/<模板>$<地标 id>.json` | `{ level, kind, param, custom_data }` |

- 子对象导出 ID = `<模板名>$<本地 id>`，文件名与 ID 对齐。
- `level` 字段由编译器写入，作者文档里不写。
- 根字段 `navigation` 整文件非法。地标使用 `kind`，不再使用 `type`。
- 合法 `.nav` 不产出运行时文件。出现 `navigation_points/` 会报「已废弃」。
- 重复导出路径会报编译错误。

## 三维体积

地图模板在中间用 Three.js 看体积，不画世界、方块或烘焙贴图。矩形是盒子，圆是沿 Y 的圆柱，多边形在 XZ 上挤出，地标是小球。

- 点击视口后WASD移动、Q/E升降，Shift加速；右键环绕，中键平移，滚轮推拉。相机不进文档或撤销栈，离焦与松键停止移动。
- 矩形和圆选择工具后，点击起点、再点终点创建，也可按住左键拖出范围。多边形逐点点击、Enter完成。它们落在当前选中的区域；没有选中区域时新建一个。创建平面跟随当前编辑高度；可选整方块或0.1方块吸附，按住Alt临时使用0.1方块。预览不写历史，完成才提交一次；Esc取消。
- 选择工具可以拖动体积、角点、半径、多边形顶点和高度。地标可在视图里移动，Y 也能拖。一次手势只记一帧撤销。
- `y: "all"` 使用淡色参考轮廓和一个方块高的编辑带，不显示高度控制点；参考高度不会写回文档。侧栏仍区分「全部高度」和「限定高度」。
- 侧栏列出矩形的 X/Z 端点、圆的圆心和半径、多边形顶点。拖动预览时这些数字跟着变；改一个端点或高度才记一帧撤销。
- Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y。不自动写盘，仍走工作区保存。
- 解析失败时只读显示原文，避免坏 JSON 被视图盖掉。
- 左侧按「区域 → 编号体积」选择重叠对象，右侧按范围、高度、显示分组。F 对准选中对象；可切换透视、俯视、正视、侧视。相机操作不记入撤销，编辑属性不会重置相机。
- 整数区域边界语义保持不变：矩形起止端点都包含在区域内，`x:[0,0]` 是一个方块；有限高度同理。坐标支持小数。矩形与高度的最大世界面是作者最大值加 1，圆心、多边形顶点在 XZ 上加 0.5；地标 XYZ 是绝对坐标。拖动吸附的是相对起点的增量，因此原有小数不会被整方块拖动抹掉。
- 两次点击确认或拖动松手的有效变化才记入历史。绘制过程中撤销会先取消当前预览，不同时撤销上一笔修改。Esc、失焦、指针取消或意外丢失捕获也会撤回预览；两点模式中第一点的正常松手不会取消创建。切换文件后仍保留本窗口该文件的撤销历史。

## 属性与扩展数据

几何属性直接用坐标、范围、半径、顶点和高度控件编辑。地标的名称文本键、图标、最小/最大显示距离使用独立中文表单；名称译文在下方「地标本地化」填写。

「高级扩展数据」中的未知键按实际类型显示：文本框、数字框、布尔开关、空值、可折叠对象和有序列表。可在嵌套层添加、修改或删除项；未编辑的未知键保留。键名由定义该功能的脚本或附属模块决定，编辑器不为未知键编造含义。「高级 JSON」仅作为可选入口。

未完成数字、无效 JSON、尚未添加的新键会明确提示并阻止保存、切换对象或关闭页签。可以修正，也可以使用「放弃未完成编辑」；只读后仍可放弃本地输入。删除按钮写明当前体积的编号与形状；删除整个区域的操作单独折叠，并注明区域名和体积数量。删除可以撤销，显式保存后才写入工程。

## 离线与在线

默认「离线3D」模拟区域和地标体积，支持选择、拖动和参数修改，不渲染Minecraft世界。按下「游戏内」则显示完整的原生游戏区域编辑界面并接管键鼠；浏览器侧栏仍能编辑属性，切回离线3D可预览同一份结果。两端共用当前 `.level` 草稿、撤销/重做和显式保存。

先在「编辑 → 游戏开发服务器」连接游戏门户，默认 `127.0.0.1:8765`。网页地址和模组门户是两个端口；如启动时改了门户端口，以游戏日志为准。游戏内须已进入世界。申请 `level.edit` 成功后才开始串流，占用、断线或只读会明确说明。

原生编辑器由本项目实现，不需要Axiom。V选择、B矩形、C圆、P多边形（Enter完成）、L地标。点矩形/圆后，点击起点、再点终点，也可以直接左键拖出范围；顶部始终显示当前步骤。选择工具下，首次拖动选区内部即可选中并移动，拖边角、半径、顶点和上下控制点改大小。空中选区也按实际三维表面命中。

点击视口后直接用WASD移动镜头、Q/E升降、Space升高、Shift加速；输入属性时不接管按键。右拖转向、中拖平移、滚轮推拉、F对准选中；不需要一直按住右键才能移动。默认新区域为有限高度，顶部和底部都有Y控制点，也可在两端属性中修改上下界。只读、断线或属性未应用时，会显示不能绘制的原因。

原生属性先编辑、再点击「应用属性」。错误数字保留输入；另一端更新了目标或版本时需先「重载属性」。未应用的原生表单会阻止浏览器保存和切换目标，避免丢失输入。原生「保存」和画面内Ctrl+S先确认属性，再请求网页现有S事务保存；Ctrl+Z/Y使用同一地图历史。原生文本框保留自己的文本撤销，浏览器表单和中文输入法继续按浏览器原生输入。

串流使用交互JPEG（最长边1280、目标30帧、质量0.62），浏览器不另画世界或体积；实际帧率取决于游戏渲染、读回和解码。松开、失焦或切走页面会释放输入并取消未提交的拖动。预览不写历史，松手提交只记一次，显式保存才写工程，不自动发布PAK。

## 区域环境与音乐

选中体积后，在属性面板切到「环境与音乐」。效果作用于整个区域的所有编号体积，范围、高度和控制点修改仍会保留它们。

- **环境雾**：选择玩家进入后改变环境，或有边界的空间雾；用预设、距离示意、滑块和色板调整分布、浓度、昼夜颜色、散射、噪声、风与天气。雾中灯光可添加点光／聚光、调整位置、颜色、范围和阴影。
- **天空与云**：添加原版、渐变、星空、极光、日月、全景或天空盒图层；调整顺序、可见度、混合与类型化参数。云的染色、可见度和高度单独分组。
- **画面滤镜**：组合调色、晕影、泛光、模糊、色差等滤镜，按顺序串联，逐项调强度和参数。天空与滤镜各有转场；进入／离开策略与优先级放在独立分组。
- **区域音乐**：选择声音事件并设置音乐优先级，重叠时取最高优先级。连接游戏后可在游戏客户端试听／停止。音量、播放间隔与正式切换跟随游戏音乐设置；浏览器画面串流不传输音频。

修改先留在面板输入，点击「应用效果」或正常保存时整组校验并合并到同一草稿。撤销／重做沿用地图历史；未知扩展数据保留。无效数字和跨端更新保留当前输入，不静默覆盖。空间雾需要1–4个有限高度矩形／圆形体积、体积光散射及离开恢复；不接受多边形或全部高度。

离线预览是模拟场景，用于观察距离、颜色、天空色调和部分滤镜示意；在线预览调用游戏实际渲染。预览不移动玩家，不修改运行时区域目录，不表示已保存／发布。停止、切换目标、关闭工作台、断线或租期结束后恢复原环境。在线效果库来自当前游戏资源包；离线可读取工程自定义资源的中文参数，游戏包中的其他条目需连接游戏并刷新资源。

### 我的方案与着色器

雾的预设只是起点，所有参数都可以自定义。展开「我的效果方案与资源」，为当前组合命名并「保存为新方案」；其他区域选择方案后「使用方案」，再应用或保存。这会复用雾、天空、滤镜、转场和音乐，不改变几何或自定义数据。方案库随工程共享，旧版本冲突需要在协作面板处理。

「制作自定义着色器」打开独立窗口，可以选择天空、滤镜或转场模板，编辑GLSL与参数，并给参数写中文标签。日常使用时显示色板、滑块、开关和向量，英文参数名只用于源码。已有图层的「编辑资源／制作副本」可读工程资源，或复制游戏资源到工程命名空间。

「保存资源」将定义和GLSL作为一个工程事务保存；随后把资源加入当前区域的效果输入，应用／保存区域后写入`.level`。窗口有未保存源码时，会提示先处理资源。「编译并预览」需要在线工作台，在真实游戏GPU上验证；错误信息保留输入和上一次成功预览，不会自动覆盖工程。GLSL的include与贴图从当前游戏资源读取，新增工程依赖需先导出客户端PAK并在游戏里重载。关闭或「停止预览」恢复游戏环境。离线可制作、保存源码并修改参数，无法运行游戏着色器。

资源位于`assets/<namespace>/rpgtoolkit/effects/<类型>/<路径>.json`和同名`.glsl`，客户端／合并PAK导出会包含它们及共享include和引用纹理，游戏从该PAK的标准命名空间读取；服务端包不包含客户端资源；方案库位于`meta/region-effect-presets.json`，仅随工程ZIP保留。游戏内「制作效果 / 网页资源编辑」会打开已绑定网页的制作窗口，游戏内属性面板负责已加载效果的可视化参数调整。

## 地图魔杖

1. 用 `/rpgtoolkit region wand` 获取魔杖（需op2），或在创造模式RPGToolKit标签页获取。主手右键打开原生「地图区域编辑器」，使用独立世界镜头快捷选区和修改属性。
2. 浏览器打开目标 `.level` 后进入「游戏内」，或保持离线3D并启用「魔杖圈选」绑定；游戏工作台会使用这份网页地图。没有绑定时是当前世界的本地内存草稿，「复制」只导出JSON，不表示已保存工程。
3. 也可左键方块选点1、Shift+左键方块选点2。游戏显示三维框和近边界网格墙。右键工作台中的「采用魔杖选框」可新建区域或追加当前区域；两端点包含在内，单方块选框不退化。
4. 两端属性、控制点、撤销和重做同步同一草稿；保存经S确认后才写 `.level`。世界相机不移动服务端玩家，关闭工作台恢复正常相机。

地图魔杖不会破坏所选方块。这个功能是地图作者的几何选择和可视化，不包括Residence的主人、成员、收费或方块保护规则。旧网页地图瓦片服务与订阅已删除，离线3D和在线游戏串流继续保留。

## .nav（导航器）

```json
{
  "id": "camp",
  "level": "hub",
  "track": { "type": "landmark", "ref": "hub$old_tower" }
}
```

- `track.type` 只能是 `landmark`。`track.ref` 是运行时地标 ID：`<模板>$<地标>`。
- 编译时检查所属模板与地标是否存在。
- 不写坐标、`param` 或 `custom_data`。写了会被整份拒绝。
- **旧版 `.nav`（`dimension` / `label` / `radius` / `public` / `entity_*`）会被明确拒绝**，不静默丢字段。
- 不做到达判定。导航只给出方向和距离。

## 本地化

`display_name` 是**语义键**，不是明文。译文与 `.quest` / `.kit` 同布局：

- `.level` → `assets/<locale>/lang_level/<模板名>.lang`
- `.nav` → `assets/<locale>/lang_nav/<名称>.lang`

导航器的 `display_name` 固定使用键 `display_name`，写在导航器编辑区的显示名里，不进 `.nav` JSON。地标建议用 `<地标 id>.display_name`；在模板编辑区下方的「本地化文本」里填写当前语言译文。地标的 `display_*` 仍放在地标 `custom_data`。

## 已知边界

- 不提供到达判定、接近半径或公开标记。
- 模板改名会改变其所有子对象的导出 ID；引用方需自行处理。
- 跨维度、跨服转移不在本模型内。
