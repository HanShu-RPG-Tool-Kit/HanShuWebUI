# 关于汉书

**HanShu**（汉书）是一套 RPG 内容创作工具。

本应用是 Web / 桌面壳（Tauri）前端。进度流程、礼包、剧本等功能仍在迭代中；**协议与用法以应用内帮助为准**（见 [文档索引](#docs)），实现细节以源码为准。
