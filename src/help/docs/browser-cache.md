# WebUI 浏览器缓存：能存什么、不能存什么

本文说明 HanShu **C 侧**（浏览器 / 桌面 WebView）在本机存储里放了什么、刻意不放什么，以及刷新页面后的恢复行为。工程权威数据始终在 **S**；缓存不是「已保存」。

## 原则

| 原则 | 含义 |
| --- | --- |
| S 是工程写入权威 | 缓存不能替代事务回执；看见「本地已暂存」≠「工程已保存」 |
| 会话令牌不进浏览器存储 | 不写 URL、Cookie、`localStorage` / `sessionStorage` / IndexedDB |
| 密码不缓存 | 「最近连接」只记地址与用户名 |
| 刷新可丢会话 | 内存中的临时会话在 F5 后失效；需按下方规则恢复连接 |

## 刷新（F5）后会怎样

| 场景 | 现状 |
| --- | --- |
| **本机工程**（经本机宿主 / 桌面打开） | 会把最近打开的本机路径记在 `localStorage`（`hanshu.projectResume.v1`）。浏览器刷新后**自动按路径重新打开**（向本机服务申请新会话，不读旧令牌）。桌面宿主启动时仍走自带的本机连接。 |
| **远端 / 分享登录** | 只记住地址、用户名、工程名。刷新后**弹出登录框并预填**，须重新输入密码；**不会**静默重连（无令牌可恢复）。 |
| **主动「关闭工程」** | 清除自动恢复意图，下次打开页面不会自动连上。 |
| **草稿与待确认提交** | 见下表：`sessionStorage` / IndexedDB 可能仍在；重新连上同一工程与主体后，按既有恢复路径取回。清除站点数据会丢掉它们。 |

自动恢复失败时（本机服务未起、路径失效等）会提示错误，并打开「打开工程」对话框便于手动选择。

## 现状一览

### 可以存（C 侧状态 / 恢复线索）

| 存储 | 键 / 库（示意） | 内容 | 刷新后 |
| --- | --- | --- | --- |
| `localStorage` | `hanshu.projectResume.v1` | 上次工程意图：本机路径，或远端 url+用户名（无密码/令牌） | 用于自动重连或预填登录 |
| `localStorage` | `hanshu.recentLocalProjects.v1` | 最近本机工程列表（路径、名称） | 打开对话框里点选 |
| `localStorage` | `hanshu.recentConnections.v1` | 最近远端连接（地址、用户名、工程名） | 点选填回；不存密码 |
| `localStorage` | `hanshu.serverUrl` 等偏好 | 上次服务地址、显示缩放、活动工作区等 UI 偏好 | 仍在 |
| `localStorage` | 游戏开发服务器 prefs | Control 主机/端口/是否自动连接等 | 仍在；Control 会再连 |
| `sessionStorage` | `hanshu.projectDraft:…` | 本窗口未提交正文草稿（按工程+主体） | **同标签页 F5 仍在**；关标签页可能丢 |
| `sessionStorage` | 窗口名、编辑事务窗口作用域等 | 本窗口身份相关 | 同标签页保留 |
| IndexedDB | 编辑事务日志（提交 outbox） | 待确认 / 未知结果的提交备份 | 可按工程+主体恢复；**不是**令牌 |
| IndexedDB | `hanshu.itemSnapshots.v1` | 物品展示快照（名称/tooltip/图标） | 仍在；打开时从 IDB 异步回填内存。强制刷新不先清空，等新快照覆盖。过期文件 `display` 会 ingest 为 stale 并排队更新 |
| IndexedDB | `hanshu.assets.v1` | 资源 blob 草稿投影 | 带**每次页面运行时命名空间**；整页刷新后旧 blob 键不再复用，需从 S/草稿重建 |

其它：TTS 供应商凭据等目前也可能落在 `localStorage`（明文），见配音相关文档；桌面侧宜再加固。

### 不能存 / 禁止当权威

| 内容 | 原因 |
| --- | --- |
| **会话令牌** | 安全边界；刷新后必须重新登录或由本机宿主签发新会话 |
| **密码** | 同上 |
| **Admin 恢复凭证** | 宿主不得把 owner 恢复材料交给网页存储 |
| **工程目录写权限 / 文件句柄** | C 不持有浏览器 FS 写句柄或绕过 S 的写盘 IPC |
| **把缓存当成 S 已保存** | 草稿、快照、最近列表都不是共享工程事实 |
| **跨标签页共用的资产 IDB 草稿键** | 资产缓存刻意按运行时隔离，避免多标签互相踩 |

## 与「最近打开」的关系

- **最近本机工程 / 最近连接**：手动列表，最多约 12 条。
- **自动恢复（`projectResume`）**：只记**当前**应恢复的那一个意图；主动关闭工程会清掉。

二者都可删「最近」条目；清站点数据会一并清掉自动恢复。

## 开发注意

- 新增「刷新后还要在」的状态前，先问：是 C 侧偏好，还是必须进 S 事务？令牌类禁止落盘。
- 本机自动重连依赖本机服务仍可用且路径有效；失败要可手动打开，不要死循环重试。
- 更细的事务 / 草稿边界见[多人协作编程指南](#collaboration-programming)；用户操作见[连接与协作](#collaboration-guide)。
